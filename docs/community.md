### Build

Create an app, library, bot, or integration. Share early work and discuss the parts you’re figuring out.

[Explore the Development Kit →](/development-kit.html)

</article>
<article>

### Test

Try releases and report what happened, what you expected, and which client or version you used. Report app-specific bugs to that app’s repository.

[Report an MDK issue](https://github.com/marmot-protocol/mdk/issues)

</article>
<article>

### Improve

Help with documentation, examples, design, translations, or clearer explanations. You don’t need to write code to make a useful contribution.

[Find a project on GitHub](https://github.com/marmot-protocol)

</article>
<article>

### Explore

Ask questions, discuss protocol ideas, and help identify what people need from private communication.

[Explore the specification](https://github.com/marmot-protocol/marmot)

</article>
